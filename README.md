# st_project

보고서에 적을 쉬운 버전
왜 이 주제인가 (팀이 씁니다)
우리 팀은 날씨가 사람의 감정에 미치는 영향을 매일 듣는 음악으로 확인해 보고 싶어 이 주제를 골랐다. 보통 비가 오거나 해가 짧아지면 기분이 우울해져서 슬픈 노래를 더 많이 들을 거라고 생각한다. 하지만 실제로도 사람들이 슬픈 노래를 찾는지, 아니면 기분을 풀려고 신나는 노래를 듣는지 데이터로 직접 확인해 보고 싶었다.

[학번] [팀원 이름]: 나는 상담심리를 꿈꾸며, 사람들이 우울할 때 기분을 어떻게 달래는지 궁금했다. 날씨가 흐릴 때 슬픈 노래를 들으며 감정을 푸는지, 아니면 신나는 노래로 기분을 전환하는지 데이터로 확인하고 싶었다.

[학번] [본인 이름]: 나는 임상심리를 꿈꾸며, 햇빛이 줄어들 때 사람들이 왜 우울해지는지 관심이 많다. 설문조사 대신 음원 차트 데이터로도 날씨에 따른 사람들의 감정 변화를 볼 수 있을지 궁금해 이 주제를 제안했다.

구술 평가용 3줄 암기 키워드
면접 때 아래 키워드만 머릿속에 떠올리면 자연스럽게 말할 수 있습니다.

팀 공통: 날씨와 감정 → 진짜 슬픈 노래를 들을까, 신나는 노래를 들을까?

팀원(상담): 우울할 때 기분 달래는 법 → 슬픈 노래로 공감 vs 신나는 노래로 전환

본인(임상): 햇빛이 줄면 우울해지는 현상 → 설문 대신 차트 데이터로 감정 변화 확인
